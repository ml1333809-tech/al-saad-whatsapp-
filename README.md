3. ارفع هذا المجلد (`baileys_cloud_engine`) إلى حسابك في **GitHub** واربطه مع Render.

5. بمجرد انتهاء البناء (خلال دقيقة واحدة)، سيعطيك Render رابطاً خاصاً بك مثل:
